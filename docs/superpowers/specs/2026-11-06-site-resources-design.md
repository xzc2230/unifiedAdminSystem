# 站点资源与隔离设计

日期：2026-11-06。依据用户已确认的平台设计及本轮“可以”推进第一阶段。实施位置为现有 `upstream/JeecgBoot`；保留已有锁文件修改和本地运行配置。

## 交付范围

站点登记（名称、环境、启停）、HTTP/HTTPS 目标地址登记、域名绑定与 DNS TXT 验证、站点成员（管理员/运营/只读）和追加操作记录。提供一个后台页面及 REST 接口。不部署流量执行器；这里的启停仅是资源状态，不代表公网流量已经切换。

采用现有单体后台新增 `org.jeecg.modules.siteplatform` 包，Vue 页面位于 `src/views/siteplatform/resources`。复用系统身份、租户及菜单授权。相比复用 Online 动态表，手写服务更便于强制资源授权、并发检查和域名验证；相比独立资源服务，无需增加运行组件。

## 隔离与授权

每次请求从 Shiro 登录身份取得用户 ID，租户请求头只用于选择上下文；必须向数据库核实租户正常、有效期和用户正常成员关系。系统全局租户开关不作为本模块安全前提，平台管理员也不能绕过成员校验。

所有业务查询显式绑定 tenant_id。站点创建人自动成为站点管理员；站点成员仅能添加当前租户内正常用户。站点管理员管理成员，运营可编辑站点及目标、绑定/验证域名，只读仅能查询。除站点授权外，接口还需要平台菜单权限。创建、修改等请求使用白名单 DTO，不接受 tenant_id、创建者、验证状态等受保护字段。

无站点权限与资源不存在使用相同拒绝结果。首期不提供导出、批量修改、AI 工具或跨租户管理接口。站点管理员不能移除或降级自己，避免失去管理入口。站点暂不提供删除，避免后续发布引用悬空。

## 数据与并发

新增 sp_site、sp_site_member、sp_site_target、sp_domain_binding、sp_resource_audit。ID 使用随机 UUID 的 32 字符形式。站点行锁串行化站点写操作、成员授权与撤销。目标和域名必须通过已授权的父站点定位，不能通过修改 siteId 转移归属。

域名按 IDN ASCII、小写、去除单个末尾点规范化，拒绝协议、路径、端口、IP、通配符、下划线及非法标签；规范化主机名全局唯一。解除绑定删除当前占用，保留审计，不提供隐式跨站点转移。目标地址不发起网络连接，只允许无凭证、无 fragment 的 HTTP/HTTPS 公网域名地址；后续执行器仍须校验 DNS 解析结果、重定向及内网地址，登记校验不构成完整 SSRF 防护。

## 域名归属

绑定生成 256 位随机挑战，30 分钟有效。授权运营/管理员可读取 `_jeecg-verify.<hostname>` 的 TXT 名称和值。验证使用系统 DNS，超时及查无记录返回可重试失败；数据库按挑战值及到期时间条件更新，避免 DNS 查询期间旧挑战或已删除绑定生效。验证成功只证明当前一次 DNS 控制权，不签发证书、不修改 DNS、不切流、不自动重新验证长期归属。

## 审计与部署

变更和审计在同一事务提交，审计不保存 DNS 挑战、密码或令牌。页面只读展示记录，不提供修改/删除审计接口。数据库 DBA 仍有修改能力；这里不声称具备防 DBA 篡改能力。

独立 SQL 建表和菜单迁移由发布流程执行，生产不依赖自动 Flyway。生产应用账号对 sp_resource_audit 仅 SELECT/INSERT，其余业务表按 CRUD 最小授权。已有全库 UPDATE/DELETE 授权需先收敛，单纯追加表级授权不会撤销已有库级权限。

## 验收

- 两租户、三站点角色覆盖列表、详情、更新、嵌套资源和成员管理；伪造租户头、跨站点 ID 和请求体归属字段不能越权。
- 域名规范化冲突、非法目标、DNS 错误/过期/成功、解除绑定均有用例。
- 本地构建和隔离测试通过；菜单与 SQL 可单独安装；文档区分资源登记和真正上线发布。
