# 应用编辑界面优化 Implementation Plan

**Goal:** 新增与编辑应用共用分组清晰、适配小屏的表单。

**Architecture:** 在 PackagePage 的原有表单内增加仅 apps 使用的 AppEditor；保留原有 model、字段定义、字典、校验入口和保存接口。

**Tech Stack:** Vue 3、TypeScript、Ant Design Vue、Less。

- [x] 新增 AppEditor.vue：基础信息、访问控制、风控阈值、来源黑名单四个分区。基础信息和阈值使用双列网格；模式使用字典驱动的单选卡片；白名单等布尔选项使用 0/1 开关。
- [x] PackagePage.vue 挂载专用编辑器；应用弹窗宽 960px，内部滚动、底部操作固定；其他资源继续使用通用编辑器。
- [x] 保留包名编辑禁用、地区数组转换、所有 15 个字段及 0/1 数据语义；不新增强制校验，不改变默认值。
- [x] 应用包 15 项现有回归测试和 pnpm build 通过；本地浏览器预览检查新增必填校验、值更新、编辑回填、包名禁用及 390px 手机布局。预览使用示例字典与数据，未向业务后端提交记录。
